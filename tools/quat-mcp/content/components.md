## Components

A JSON object keyed by component name. Updates merge: omitted fields keep their values. Unknown names/fields are rejected with the list of known ones. Units: metres, seconds, degrees; Y is up.

- **transform**: `position` [x,y,z] (local, relative to the parent); `rotation` [x,y,z] Euler degrees applied in YXZ order (x = pitch, y = yaw/heading, z = roll); `scale` number or [x,y,z]; `look_at` [x,y,z] world point to face (an entity's forward is -Z). `world_position` is read-only.
- **primitive**: `shape` cube|sphere|plane|cylinder|cone|capsule (about unit size, centred on the position — size it with transform.scale; a cube scaled [w,h,d] rests on y=0 at position y=h/2); `color` `"#rrggbb"` / `"#rrggbbaa"` sRGB hex or linear [r,g,b,a] (alpha < 1 = see-through); `metallic` 0..1; `roughness` 0..1; `emissive` linear [r,g,b] (HDR, > 1 glows); `shader` a material shader name (`shader_list`; `"standard"` = built-in PBR) — the shader computes the surface from these fields and `shader_params` (up to 8 numbers, its free knobs); with a shader the object stays opaque.
- **material**: per-entity overrides of the PBR factors the entity's material is drawn with (primitive or glTF mesh; the shared asset is untouched): `base_color`, `emissive`, `metallic`, `roughness`, `occlusion_strength`, `normal_scale`, `alpha_cutoff`, `transmission` (> 0 = glass), `ior`, `attenuation_color`, `attenuation_distance`, `thickness`, `clearcoat`, `clearcoat_roughness`; `null` drops an override. Prefer `material_set`, which also edits a primitive's own colour/metallic/roughness/emissive.
- **`point_light`**: `color` linear [r,g,b]; `radius` (range, m); `intensity` >= 0.
- **`dir_light`**: `direction` [x,y,z] (the light's travel direction); `color` linear [r,g,b]; `intensity`. Prefer `environment_set` for the sun, or `time_set` to have a world clock drive it.
- **camera**: `fov_deg` 1..179; `near`; `far` (> near); `active`. Physical lens: `aperture_f` (f-number 0.7..64, default 2.8; lower = shallower depth of field, brighter); `shutter_s` (exposure time, s, default 0.02; also the motion-blur length); `iso` 25..409600 (default 100); `sensor_height_mm` (default 24, full frame); `focal_length_mm` (0 = use `fov_deg`, else it sets the field of view from the sensor, e.g. 35 wide, 85 portrait); `focus_distance_m` (the distance that is sharp with `dof` on). Aperture, shutter and ISO set the exposure only with the `exposure.physical` render setting.
- **collider**: `shape` box|sphere|capsule; `half_extents` [x,y,z] (> 0); `offset` [x,y,z]; `sensor` (trigger volume, no collision response).
- **rigidbody**: `motion` static|kinematic|dynamic; `mass` (kg); `friction` 0..10 (default 0.2); `restitution` 0..1 (bounciness); `gravity_factor` -10..10 (scales the scene gravity); `linear_damping` / `angular_damping` 0..100 (default 0.05). Pair with a collider.
- **character**: `radius`; `half_height`; `speed` (m/s) — capsule character controller. Characters collide with each other and with bodies; drive one with `character_move`.
- **joint**: a physics joint from this entity's rigid body to `target` (entity id or unique name; null = the world). `type` fixed|point|hinge|slider|distance; `anchor` [x,y,z] (pivot, this entity's local space); `axis` [x,y,z] (hinge / slider, local); `target_anchor` [x,y,z] (distance: the other end, in the target's local space or world space); `limits` [min,max] or null (hinge: degrees, min in [-180,0], max in [0,180]; slider: metres, min <= 0 <= max; distance: metres, 0 <= min <= max; none for fixed / point); `motor` null or {`mode` velocity|position, `target` (deg/s or deg for hinges, m/s or m for sliders), `max_force` (N·m / N, 0 = unlimited)} (hinge and slider only). Read-only `active` is true while the constraint exists (in play mode, once both bodies exist and one is dynamic). A fixed joint keeps the current relative pose; angles and positions count from the pose the joint is built in. The joint is rebuilt whenever either body is (a `physics_set` to or from static, a collider edit), and the rebuilt joint measures from the bodies' pose at that moment, not the authored one: a hinge that had swung 60° gets its limits and position-motor target counted from 60°.
- **nav_agent**: `target` [x,y,z]; `speed` (m/s); `ground_offset`; `active`. Needs a baked navmesh (`nav_bake`).
- **behavior**: `source` (behaviour-tree JSON object or its text); `enabled`.
- **patrol**: `points` [[x,y,z],...]; `loop`. Walked by the entity's `nav_agent`.
- **script**: `path` (Lua file relative to assets/scripts/, e.g. "coin.lua"; required when adding); `enabled`; `properties` {name: number | true/false | string | [x,y,z]} overriding the script's declared properties (merged per name, `null` removes one). Runs in play mode; write the file with `script_create`.
- **terrain**: `seed`; `resolution` 17..8193; `tile_size` (m); `height` (m); `octaves` 1..16; `frequency` 0.05..64 (noise periods across a tile; lower = broader mountains); `gain` 0.1..0.9 (octave persistence; higher = more rugged); `warp` 0..4; `erosion` droplets|grid (grid: GPU-synthesised); `droplets` (droplet count, 0..50000000); `erosion_steps` (grid steps, 0..5000; resolution² × steps ≤ 1025² × 5000); `erosion_relax` (grid: cycles that bring slopes down to the talus angle, 0..8, default 3, 0 = off; the full multigrid needs a 2^n+1 `resolution` such as 513 or 1025, other sizes stop coarsening early and relax less); `erosion_talus` 0.05..4 (grid: tan of the steepest slope thermal weathering keeps; 1 = 45 degrees, rugged peaks); `erosion_rain` 0..1 (grid: m/s of rain), `erosion_capacity` 0..20 (sediment capacity), `erosion_rate` 0..10 (dissolution rate, 1/s) — more rain / capacity / rate carve deeper gullies; `erosion_thermal` 0..1 (share of the excess over the talus slope moved per step; lower keeps faces from flattening into planes); `gpu` (synthesise on the GPU); `snowline` (m); `streaming`; `stream_radius` 0..8 (tiles). The whole configuration has one budget: the (2 × `stream_radius` + 1)² tiles kept loaded (1 when not streaming) × `resolution`² must fit about 2 GiB (e.g. 1025 at radius 4, 2049 at radius 2, one 8193 tile), and `droplets` × tiles ≤ 50000000; the error names the largest values that fit. Only shape fields (`seed`, `resolution`, `tile_size`, `height`, `octaves`, `frequency`, `gain`, `warp`, `erosion`, `droplets` and the `erosion_*` fields) regenerate the terrain, which can take a while for big streamed worlds; `snowline` applies at once, `stream_radius` keeps the loaded tiles and loads or drops the outer ring, and `gpu` applies to the next tile generated.
- **`instanced_mesh`**: many copies of one model on ONE entity (forests, rocks) — prefer it over many entities. `gltf` (path relative to the project root; `node` = only that node's subtree) or, with gltf empty, the primitive fields `shape`/`color`/`metallic`/`roughness`/`emissive`/`shader`/`shader_params`; `cast_shadows`; `instances` [{position, rotation, scale} or [x,y,z], ...] relative to the entity (omitted while a scatter generates them); `instance_count` is read-only.
- **`scatter`**: procedural placement of the entity's `instanced_mesh` on the terrain around the entity: `seed`; `area` rect|circle; `size` [x,z] (m); `radius` (m); `density` (per m²); `min_spacing` (m); `pattern` `poisson`|`jittered_grid`; `scale` [min,max]; `random_yaw`; `align_to_normal` 0..1; `base_offset` (× scale; 0.5 seats a unit primitive on the ground); `mirror` 0..1 (fraction of placements mirrored, for variety); `slope` [min,max] degrees; `height` [min,max] m; `max_instances`. Same seed = same placements.
- **`world_clock`**: the scene's date, time and place (one per scene; `time_set` / `time_get` are the convenient way to edit it). `enabled`; `datetime` ISO-8601 ("2026-06-21T05:30" is local time, or add "Z" / "+02:00"); `utc_offset_h` -14..14; `latitude_deg` / `longitude_deg`; `north_offset_deg` (0: north is -Z); `time_scale` clock seconds per simulated second (0 freezes); `fixed_day` (loop one day); `drive_sun` (the first `dir_light` follows the Sun); `sun_intensity` (full-sun light intensity).
- **grass**: dense wind-animated grass the GPU grows around the camera each frame (one field per scene: the first grass entity; its transform is unused). `seed`; `density` blades per m² 0..1000 (40 = lawn; cost grows with density × radius²); `radius` m 0..500; `blade_height` [min,max] m; `blade_width` [min,max] m; `base_color` / `tip_color` `"#rrggbb"` sRGB or linear [r,g,b]; `wind_strength` 0..4 (how strongly the blades bend in the wind; 1 bends tips ~45° in a fresh breeze); `wind_direction` [x,z] (ignored while the scene has a weather); `wind_frequency` Hz; `slope` [min,max] degrees and `height` [min,max] m of the ground it grows on (density thins smoothly over the last 8 degrees below the max slope, so a few steep texels thin the field instead of punching holes); `terrain_only` (false = also flat ground at `ground_y` where no terrain is loaded); `lod_start` 0..1 (fraction of radius where blades thin out); `far_density` 0..1 (fraction kept at the radius).
- **`particle_emitter`**: GPU particles at the entity (sparks, fire, smoke, dust, rain); one entity per effect. Emission: `rate` per s; `burst_count` + `burst_interval` s (0 = one burst at start); `lifetime` [min,max] s; `max_particles` 1..65536 (its share of the particle budget); `enabled`; `seed` (same seed = same particles). Shape: `shape` point|sphere|box|cone; `radius` m (sphere, cone base); `box` half extents [x,y,z]; `cone_angle` degrees; `direction` [x,y,z] launch direction (entity space); `spread` degrees (point, box); `speed` [min,max] m/s. Forces: `gravity` [x,y,z] m/s² (default [0,-9.81,0]; [0,0.5,0] makes smoke rise); `drag` 1/s. Look: `size` [min,max] m start width; `size_curve` / `color_curve` up to 4 keys over the normalised age t 0..1: `{"t", "size"}` (multiplier) / `{"t", "color" ("#rrggbb" sRGB or linear [r,g,b]), "alpha" 0..1}`; `emissive` brightness multiplier (> 1 glows); `rotation` / `spin` [min,max] degrees, degrees/s; `texture` flipbook atlas under `assets/` (empty = soft disc) with `flipbook` [columns,rows], `frames`, `fps` (0 = once over the life). Rendering: `blend` additive (light: sparks, fire, magic) | alpha (order-independent transparency: smoke, dust); `lighting` unlit | lit (sun, ambient and point lights — use for smoke and dust); `space` world (trails stay behind a moving entity) | local; `soft_distance` m (fade where particles meet geometry); `sort` (stable back-to-front order). `collide` with what the camera sees (`bounce` 0..1, `friction` 0..1). Particles follow the simulation clock: pausing freezes them.
- **weather**: the scene's weather, at most one entity (prefer the `weather_set` tool). Fields as `weather_set`: `wind_dir_deg`, `wind_speed` m/s, `gustiness`, `turbulence`, `cloud_cover`, `precipitation`, `precipitation_type` "rain" | "snow", `wetness`, `snow`, `temperature_c`, `accumulate`.
- **`net_replicated`**: `net_id`.
- **animator** (edit only, present on animated glTF models): `clip` (name of the clip playing; set it to one of `clips` to switch — the new clip starts at `time` 0 unless `time` is given); `clips` (read only, the model's clips); `blend` inertialize|crossfade (how a switch blends; inertialize evaluates only the new clip); `blend_time` (s, 0 = cut); `time` (s); `speed`; `looping`.
- **`foot_ik`**: foot placement for an animated model — legs reach uneven ground (physics, else terrain) and the pelvis lowers to the lower foot. `enabled`; `pelvis`, `left_foot`, `right_foot` (joint names; empty = auto-detect); `ray_up`, `ray_down` (probe above/below the ankle, m); `max_adjust` (m); `max_foot_angle` (degrees); `smoothing` (s, spring half-life).
- **`camera_rig`**: an orbit / strategy camera that drives the entity (put `camera` on it too, for the lens; keep it a root). Targets: `focus` [x, y, z], `yaw_deg` (0 = +X, 90 = +Z), `distance` (m), and `pitch_deg` when `pitch_follows_zoom` is false. With `pitch_follows_zoom` (the default), pitch eases from `pitch_near_deg` at `min_distance` to `pitch_far_deg` at `max_distance`. `yaw_step_deg` (0 = free rotation); half-lives `focus_halflife_s`, `yaw_halflife_s`, `zoom_halflife_s`, `pitch_halflife_s` (s); `follow_ground`, `focus_ground_halflife_s`, `ground_clearance` (m); `drag_inertia_halflife_s`; `focus_lens` (default true: the camera's depth of field stays focused at the rig's distance); `bounds` {`shape`: none / rect / circle, `min`, `max` [x, z], `center`, `radius`, `margin` (m)}. `current` is read-only: the damped pose now. The tools are `camera_rig_get`, `camera_rig_set` and `camera_rig_frame`.
- **`camera_rig_input`**: names the input actions that drive the entity's `camera_rig`; empty means unused. The fields are `pan` (axis2d rate), `orbit` (axis1d rate), `orbit_delta` (axis1d per frame, e.g. mouse delta while a button is held), `pitch_delta`, `zoom` (wheel steps; positive zooms in, toward the cursor), `drag_pan` (a button action with a `drag` trigger that grabs the world), plus `pan_speed` (fraction of the distance per second), `orbit_speed_deg`, `orbit_delta_deg`, `zoom_step` and `zoom_to_cursor`.
- **`spline`**: a curve through control points (entity-local metres). `kind`: `centripetal_catmull_rom` (default; smooth through every point), `cubic_bezier` (anchor, handle, handle, anchor, …: 3k + 1 points, 3k when closed) or `polyline`. `points`: each `[x, y, z]` or `{"position": [x, y, z], "width": 1, "height": 0, "tags": 0}`; width is across the curve, height above it. `closed`, `follow_ground` (drape on the terrain, default true), `ground_offset`, `network` (splines sharing a non-zero number form a junction graph) and `id` (stable id in it; 0 = the entity id). The tools are `spline_get`, `spline_set`, `spline_sample`, `spline_closest`, `spline_crossings`, `spline_offset`, `spline_network` and `spline_fit`.
- **mesh**: read only (glTF provenance).

`scene_components` lists what the running engine supports.
