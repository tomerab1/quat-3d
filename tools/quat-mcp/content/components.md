## Components

A JSON object keyed by component name. Updates merge: omitted fields keep their values. Unknown names/fields are rejected with the list of known ones. Units: metres, seconds, degrees; Y is up.

- **transform**: `position` [x,y,z] (local, relative to the parent); `rotation` [x,y,z] Euler degrees applied in YXZ order (x = pitch, y = yaw/heading, z = roll); `scale` number or [x,y,z]; `look_at` [x,y,z] world point to face (an entity's forward is -Z). `world_position` is read-only.
- **primitive**: `shape` cube|sphere|plane|cylinder|cone|capsule (about unit size, centred on the position — size it with transform.scale; a cube scaled [w,h,d] rests on y=0 at position y=h/2); `color` `"#rrggbb"` / `"#rrggbbaa"` sRGB hex or linear [r,g,b,a] (alpha < 1 = see-through); `metallic` 0..1; `roughness` 0..1; `emissive` linear [r,g,b] (HDR, > 1 glows).
- **material**: per-entity overrides of the PBR factors the entity's material is drawn with (primitive or glTF mesh; the shared asset is untouched): `base_color`, `emissive`, `metallic`, `roughness`, `occlusion_strength`, `normal_scale`, `alpha_cutoff`, `transmission` (> 0 = glass), `ior`, `attenuation_color`, `attenuation_distance`, `thickness`, `clearcoat`, `clearcoat_roughness`; `null` drops an override. Prefer `material_set`, which also edits a primitive's own colour/metallic/roughness/emissive.
- **`point_light`**: `color` linear [r,g,b]; `radius` (range, m); `intensity` >= 0.
- **`dir_light`**: `direction` [x,y,z] (the light's travel direction); `color` linear [r,g,b]; `intensity`. Prefer `environment_set` for the sun.
- **camera**: `fov_deg` 1..179; `near`; `far` (> near); `active`.
- **collider**: `shape` box|sphere|capsule; `half_extents` [x,y,z] (> 0); `offset` [x,y,z]; `sensor` (trigger volume, no collision response).
- **rigidbody**: `motion` static|kinematic|dynamic; `mass` (kg); `friction` 0..10 (default 0.2); `restitution` 0..1 (bounciness); `gravity_factor` -10..10 (scales the scene gravity); `linear_damping` / `angular_damping` 0..100 (default 0.05). Pair with a collider.
- **character**: `radius`; `half_height`; `speed` (m/s) — capsule character controller. Characters collide with each other and with bodies; drive one with `character_move`.
- **joint**: a physics joint from this entity's rigid body to `target` (entity id or unique name; null = the world). `type` fixed|point|hinge|slider|distance; `anchor` [x,y,z] (pivot, this entity's local space); `axis` [x,y,z] (hinge / slider, local); `target_anchor` [x,y,z] (distance: the other end, in the target's local space or world space); `limits` [min,max] or null (hinge: degrees, min in [-180,0], max in [0,180]; slider: metres, min <= 0 <= max; distance: metres, 0 <= min <= max; none for fixed / point); `motor` null or {`mode` velocity|position, `target` (deg/s or deg for hinges, m/s or m for sliders), `max_force` (N·m / N, 0 = unlimited)} (hinge and slider only). Read-only `active` is true while the constraint exists (in play mode, once both bodies exist and one is dynamic). A fixed joint keeps the current relative pose; angles and positions count from the pose the joint is built in.
- **nav_agent**: `target` [x,y,z]; `speed` (m/s); `ground_offset`; `active`. Needs a baked navmesh (`nav_bake`).
- **behavior**: `source` (behaviour-tree JSON object or its text); `enabled`.
- **patrol**: `points` [[x,y,z],...]; `loop`. Walked by the entity's `nav_agent`.
- **terrain**: `seed`; `resolution` 17..8193; `tile_size` (m); `height` (m); `octaves` 1..16; `warp` 0..4; `erosion` droplets|grid (grid: GPU-synthesised); `droplets` (droplet count, 0..50000000); `erosion_steps` (grid steps, 0..100000); `gpu` (synthesise on the GPU); `snowline` (m); `streaming`; `stream_radius` 0..8 (tiles).
- **`instanced_mesh`**: many copies of one model on ONE entity (forests, rocks) — prefer it over many entities. `gltf` (path relative to the project root; `node` = only that node's subtree) or, with gltf empty, the primitive fields `shape`/`color`/`metallic`/`roughness`/`emissive`; `cast_shadows`; `instances` [{position, rotation, scale} or [x,y,z], ...] relative to the entity (omitted while a scatter generates them); `instance_count` is read-only.
- **`scatter`**: procedural placement of the entity's instanced_mesh on the terrain around the entity: `seed`; `area` rect|circle; `size` [x,z] (m); `radius` (m); `density` (per m²); `min_spacing` (m); `pattern` poisson|jittered_grid; `scale` [min,max]; `random_yaw`; `align_to_normal` 0..1; `base_offset` (× scale; 0.5 seats a unit primitive on the ground); `slope` [min,max] degrees; `height` [min,max] m; `max_instances`. Same seed = same placements.
- **grass**: dense wind-animated grass the GPU grows around the camera each frame (one field per scene: the first grass entity; its transform is unused). `seed`; `density` blades per m² 0..1000 (40 = lawn; cost grows with density × radius²); `radius` m 0..500; `blade_height` [min,max] m; `blade_width` [min,max] m; `base_color` / `tip_color` `"#rrggbb"` sRGB or linear [r,g,b]; `wind_strength` 0..4 (1 bends tips ~45°); `wind_direction` [x,z]; `wind_frequency` Hz; `slope` [min,max] degrees and `height` [min,max] m of the ground it grows on; `terrain_only` (false = also flat ground at `ground_y` where no terrain is loaded); `lod_start` 0..1 (fraction of radius where blades thin out); `far_density` 0..1 (fraction kept at the radius).
- **`net_replicated`**: `net_id`.
- **animator** (edit only, present on animated glTF models): `time` (s); `speed`; `looping`.
- **mesh**: read only (glTF provenance).

`scene_components` lists what the running engine supports.
