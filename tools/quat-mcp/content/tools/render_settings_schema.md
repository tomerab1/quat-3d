The descriptor table of everything tunable: `{groups: [{name, label, hint, fields: [{name, label, type: "boolean"|"number"|"integer", min, max, default, unit, hint}]}], material: [{name, label, kind: "color4"|"color3"|"scalar", min, max, hint, primitive_field}]}`. `groups` is what `render_settings_set` accepts; `material` is what `material_set` accepts. Call it once per session to learn ranges and units instead of guessing.
