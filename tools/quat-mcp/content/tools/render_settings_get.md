Read the renderer's tunable settings — the same values the editor's Renderer panel shows. Returns `{group: {field: value}}` for every group, or only `group` when given: `exposure` (auto, compensation_ev, key, min_exposure, max_exposure, adaptation_s), `bloom` (enabled, threshold, knee, intensity, radius), `taa` (enabled, feedback), `upscaler` (mode — `auto` (default: `quality` on HiDPI displays, else `native_aa`), `native_aa`, `quality`, `balanced`, `performance` — render_scale, sharpness, backend; `debug_stats` reports the resulting render and output resolution), `shadows` (enabled, max_distance, cascades, split_lambda, fit_to_depth, blend_band, pcf_radius, sun_size_deg, normal_bias_texels, depth_bias_texels, caster_distance, debug_cascades), `ao` (enabled, radius, strength, falloff_range, sample_distribution_power, thin_occluder_compensation, depth_mip_offset, slices, steps_per_slice, denoise_passes, denoise_blur_beta, bent_normals, specular_occlusion, multi_bounce), `contact_shadows` (enabled, length, steps, thickness, intensity), `ibl` (intensity, multiscatter, horizon_occlusion), `environment` (source, hdri_intensity, hdri_rotation_deg, hdri_sun; the HDRI file is set with `environment_set`), `ssr` (enabled, quality, max_roughness, thickness, edge_fade), `clouds` (as `environment_get`), `dof` (enabled, max_radius_px, rings), `motion_blur` (enabled, max_radius_px, samples, scale), `tonemap` (operator), `grading` (temperature_k, tint, contrast, saturation, lift_r/g/b, gamma_r/g/b, gain_r/g/b, lut, lut_contribution), `film` (vignette_natural, vignette_intensity, vignette_smoothness, grain_intensity, grain_size_px, chromatic_aberration). `exposure` also has `physical` (expose from the camera's aperture, shutter and ISO).

Read this before changing anything, so you know the starting point; `render_settings_schema` gives each field's range, default and unit.
