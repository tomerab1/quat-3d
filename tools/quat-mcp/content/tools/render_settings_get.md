Read the renderer's tunable settings — the same values the editor's Renderer panel shows. Returns `{group: {field: value}}` for every group, or only `group` when given: `exposure` (auto, compensation_ev, key, min_exposure, max_exposure, adaptation_s), `bloom` (enabled, threshold, knee, intensity, radius), `taa` (enabled, feedback), `shadows` (enabled, max_distance, cascades, split_lambda, fit_to_depth, blend_band, pcf_radius, sun_size_deg, normal_bias_texels, depth_bias_texels, caster_distance, debug_cascades), `ao` (enabled, radius, strength, falloff_range, sample_distribution_power, thin_occluder_compensation, depth_mip_offset, slices, steps_per_slice, denoise_passes, denoise_blur_beta, bent_normals, specular_occlusion, multi_bounce), `contact_shadows` (enabled, length, steps, thickness, intensity), `ibl` (intensity), `clouds` (as `environment_get`).

Read this before changing anything, so you know the starting point; `render_settings_schema` gives each field's range, default and unit.
