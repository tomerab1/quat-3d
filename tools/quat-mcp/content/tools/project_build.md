Package the open game project into a standalone game for the engine's own OS — a folder plus an archive (`.tar.gz` on Linux, `.zip` on Windows and macOS, the latter holding a signed `.app`) that a player double-clicks. Runs in the background and returns at once with `{job, state: "running", target, config, output}`; follow it with `project_build_status` until `state` is `succeeded` or `failed`. Only the files the game references ship (start scene → models, audio, scripts), plus `game.json`'s content roots; models are cooked when the engine has its asset cooker. `output` is relative to the game project (default `"dist"`); an existing package of the same name there is replaced. `config: "development"` lets the packaged game accept remote control for testing; the default `"shipping"` locks it out. `smoke_test: true` launches the package headless afterwards to prove it starts. Fails if a build is already running, no project is open, or the target is another OS.
