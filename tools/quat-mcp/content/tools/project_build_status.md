The packaging job started by `project_build`: `{job, state, progress, step, steps, step_name, package?, folder?, error?, elapsed_s, log}`. `state` is `idle`, `running`, `succeeded`, `failed` or `cancelled`; `progress` runs from 0 to 1 over the steps (validate project, collect files, stage data, lay out the package, smoke test). On success `package` is the archive and `folder` the unpacked package, both relative to the game project. On failure `error` names the problem — for a missing or out-of-project file it names the scene and entity that referenced it — and `log` shows the tail of the build output (`log_lines`, default 40). Poll every few seconds while `state` is `running`.
