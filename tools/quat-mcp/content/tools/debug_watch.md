Snapshot entities' live component values right now; call it repeatedly (between `debug_step`s, or while playing) to watch values change. Give one `entity` (id or unique name) or `entities` (up to 64), and optionally `components` to return only those, e.g. `{"entity": "Crate", "components": ["transform", "rigidbody"]}`.

Returns `{entities:[{id, name, world_position, components:{...}, missing?, nav_agent_state?}], frame, sim_time_s}`. Component fields are the same as `scene_get`. `missing` lists requested components the entity does not have. Entities with a nav agent also report `nav_agent_state` — `active`, `arrived`, `failed` (gave up), `plan_failures`, `path_partial`, `path` (waypoints), `waypoint` (current index), `stuck_s` (seconds without progress) — the first thing to read when an NPC does not move.
