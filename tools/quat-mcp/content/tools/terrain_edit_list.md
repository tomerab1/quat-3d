The terrain's edit stamps in the order they apply: `{stamps: [{id, shape, points, radius, falloff, op, strength, ...}], revision, count}`. Coordinates are world space, metres (`points` are `[x, z]`, `height` is world Y). Each stamp's id is stable: pass it to `terrain_edit_update`, `terrain_edit_remove`, or as `before` in `terrain_edit_add`. `revision` increases with every change. A scene without a terrain is `not_found`.
