Current viewport camera: `{position, yaw_deg, pitch_deg, fov_deg, near, far, near_auto, far_auto, lens}`. yaw 0 looks along +X and 90 along +Z; positive pitch looks up. `near` / `far` are the clip planes in effect (metres); `near_auto` / `far_auto` say whether each is derived from the scene or was set with `camera_set`. `lens` is the physical lens: `aperture_f`, `shutter_s`, `iso`, `sensor_height_mm`, `focal_length_mm` (0 = `fov_deg` applies) and `focus_distance_m`.
