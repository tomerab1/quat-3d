Move part of a dynamic mesh without rebuilding it. This replaces the `positions` (and optionally `normals`) of vertices `first .. first + len` of mesh `id` and keeps its triangles. Only the changed bytes are uploaded; the rest is copied on the GPU. Use it for small, frequent edits such as deforming a wall segment or animating a few vertices. For changes in topology, use `mesh_dynamic_set` or `geometry_generate` again.
