Pause the simulation: physics, characters, NPC behaviour, navigation and animation freeze, while rendering, the camera and screenshots keep working — so you can examine a frozen moment with `debug_watch`, `debug_raycast` and `screenshot`. Returns the clock `{paused, time_scale, pending_steps, steps_run, sim_frames, sim_time_s}`. Continue with `debug_resume`, or frame by frame with `debug_step`.
