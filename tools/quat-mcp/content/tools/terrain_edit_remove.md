Remove terrain edit stamps by id: `{"id": 4}` or `{"ids": [4, 7]}`. The ground under them returns to what the remaining stamps (and the generator) make of it on the next frame. Returns `{removed: [ids], missing: [ids], revision, count}`; ids that did not exist are listed in `missing` rather than failing the call. Ids are never reused, so removing the id `terrain_edit_add` returned undoes exactly that stamp. Use `terrain_edit_clear` to remove every stamp.
