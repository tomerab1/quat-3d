Rebind an input action: `{"action": "jump", "bindings": ["key:j", "gamepad:north"]}` replaces its bindings, and `"bindings": null` restores the action map's own. By default the change is saved to the player's rebinding file, which sits beside the project's defaults and never inside the game data. Pass `"save": false` for a temporary change.

Binding strings: `key:<name>` (a-z, 0-9, f1-f12, space, enter, escape, left_shift, ...) with optional `ctrl+` / `shift+` / `alt+` prefixes; `mouse:left|middle|right|x1|x2|delta|delta_x|delta_y|wheel`; `pointer`; `edge`; `gamepad:<button>` (south, east, west, north, start, dpad_up, ...), `gamepad:<axis>` (left_x, left_trigger, ...), and `gamepad:left_stick_xy` / `gamepad:right_stick_xy`. Composites are objects, e.g. `{"composite": "2d", "up": "key:w", "down": "key:s", "left": "key:a", "right": "key:d"}`.
