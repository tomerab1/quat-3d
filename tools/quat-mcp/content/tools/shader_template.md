Get the starter material shader: a complete, compiling Slang module with comments listing every input (`MaterialInput`) and output (`SurfaceSample`) field. Start every new material from it: keep `import material;`, the `struct ... : IMaterial` with its `static SurfaceSample evaluate(MaterialInput input)` function, and the last line `export struct SurfaceMaterial : IMaterial = <YourStruct>;`, then change the body and send it with `shader_create`.

Material shaders are plain Slang (HLSL-like): `float3`, `lerp`, `saturate`, `smoothstep`, `frac`, `sin`, `dot`, `normalize`, loops and helper functions are all available. They cannot declare textures, buffers or other global parameters — everything comes in through `MaterialInput`; per-entity knobs go in `primitive.shader_params` (8 numbers, read as `input.params.shader_params[0]` and `[1]`).
