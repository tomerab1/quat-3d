Describe the game project the engine has open: `{open, root, game, executable, host_target, build}`. `game` is the project's `game.json` (name, reverse-DNS id, version, start scene, window, icon, content roots), `executable` the name the packaged game runs under, `host_target` the only OS the engine can package for, and `build` the state of the last packaging job. When `open` is false the engine was started without a game project (`QUAT_GAME=<project dir>`), and `reason` says so; packaging needs one.
